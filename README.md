# Sunanth Samala — Portfolio

Personal site for Sunanth Samala, Founder × Developer.

Live: https://sunanth-developer.github.io/portfolio-/

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion + GSAP
- Lenis
- Lucide React

## Develop

```bash
npm install
npm run dev
```

## Content

Structured content lives in `src/data/`. Update `site.ts` for contact links, `projects.ts` for venture images, and the other data files to extend the dossier without rewriting components.

Place DriverSpot frames in `public/ventures/driverspot/` and add their paths to `projects.ts` → `images`.
